Что умеет NEXUS LAUNCHER

Всё необходимое для игры, сборки модов и игры с друзьями — в одном окне.

01

Запуск Minecraft

Введите ник, выберите версию и ядро. Лаунчер скачает недостающие файлы и запустит игру с модами или без них.

02

Релиз или снапшот

Переключатель Release / Snapshot / All прямо в лаунчере. В каталоге 103 стабильные версии и 761 снапшот.

03

Мод-браузер

Поиск модов на Modrinth и CurseForge, установка прямо в папку mods выбранной сборки, фильтр по версии и поддержка зависимостей.

04

Bedrock Edition

Автоопределение версии из Microsoft Store, импорт аддонов и миров, быстрые разделы Creative, паков, серверов и профиля.

05

Друзья и UPnP

Код приглашения, прямой IP-пинг Java и Bedrock, автоматическая проброс портов TCP и UDP через UPnP — без Hamachi и аренды сервера.

06

Буст FPS

Готовый пакет оптимизации: Sodium, Lithium, FerriteCore, EntityCulling, ImmediatelyFast, Clumps и другие моды для выбранного ядра.

07

Скины через Ely.by

Включите синхронизацию по нику — лаунчер подтянет скин через authlib-injector при запуске игры.

08

Мои моды

Отдельная вкладка с авторскими модами: Rick Prime Nanobots и Rick's Stuff. Установка одной кнопкой, зависимости подтягиваются автоматически.

09

Ранний доступ по ключу

Автор выдаёт персональный ключ. Он открывает новые функции раньше остальных и помечает владельца как первого тестировщика.

Как установить

Займёт пару минут. Лаунчер portable — установщик не требуется.

  1. 1

    Скачайте архив

    Нажмите кнопку скачивания и получите NEXUS LAUNCHER.zip.

  2. 2

    Распакуйте в папку

    Лучше без кириллицы в пути, например C:\Games\NexusLauncher.

  3. 3

    Запустите NEXUS LAUNCHER.exe

    При первом старте лаунчер подготовит папки для версий, модов и профилей.

  4. 4

    Выберите сборку и играйте

    Укажите ник, ядро и версию, затем нажмите «Запустить Minecraft».

Требования

Windows 10/11, интернет для загрузки игры и модов. Для актуальных версий Java нужна Java 21 — лаунчер подскажет, если версия не подходит. Для Bedrock нужен пакет из Microsoft Store.

Для раздела CurseForge нужен бесплатный API-ключ. Для Modrinth ключ не требуется.

    Частые вопросы

    Коротко о главном перед запуском.

    Это официальный лаунчер Minecraft?

    Нет. Это независимый лаунчер автора проекта для Minecraft Java Edition и запуска установленного Bedrock Edition из Microsoft Store.

    Какие версии Minecraft поддерживаются?

    В каталоге 1150 версий: 864 Java-версии с фильтром Release / Snapshot / All и 286 версий Bedrock. Из Java-ядер доступны Fabric, NeoForge, Forge, Quilt и Vanilla.

    Как играть с другом?

    Откройте вкладку «Друзья», скопируйте код приглашения и отправьте его другу. Лаунчер сам определит IP и порт, пробросит их через UPnP и подключит к миру. Для Bedrock используется порт 19132.

    Как получить ранний доступ?

    Попросите ключ у автора и введите его в разделе «Ранний доступ». Ключ привязан к браузеру через localStorage; чтобы сбросить его, нажмите «Забыть ключ».

    Можно ли играть без модов?

    Да. Кнопка «Запустить без модов» запускает выбранную сборку без установленных модов.

    Куда ставятся моды?

    В папку mods профиля выбранной связки «версия / ядро». Открыть её можно кнопкой «Папка mods» прямо в лаунчере.

    Как установить ваши моды?

    Откройте вкладку «Мои моды» и нажмите «Установить» рядом с нужным модом. Rick Prime Nanobots 3.4.1 Requires Rick's Stuff, поэтому зависимость поставится вместе с ним.
