Что умеет NEXUS LAUNCHER

Всё необходимое для игры и сборки модов — в одном окне.

01

Запуск Minecraft

Введите ник, выберите версию и ядро. Лаунчер скачает недостающие файлы и запустит игру с модами или без них.

02

Мод-браузер

Поиск модов на Modrinth и CurseForge, установка прямо в папку mods выбранной сборки, фильтр по версии и поддержка зависимостей.

03

Буст FPS

Готовый пакет оптимизации: Sodium, Lithium, FerriteCore, EntityCulling, ImmediatelyFast, Clumps и другие моды для выбранного ядра.

04

Серверы и пинг

Добавляйте серверы по IP, проверяйте их доступность и подключайтесь к нужному прямо из лаунчера.

05

Скины через Ely.by

Включите синхронизацию по нику — лаунчер подтянет скин через authlib-injector при запуске игры.

06

Настройки под себя

Выделение ОЗУ, три цветовые темы, CurseForge API-ключ и собственная папка Minecraft — всё сохраняется между запусками.

07

Мои моды

Отдельная вкладка с модами автора лаунчера: Rick Prime Nanobots и Rick's Stuff. Установка одной кнопкой, зависимости подтягиваются автоматически.

// 02

Как установить

Займёт пару минут. Лаунчер portable — установщик не требуется.

  1. 1

    Скачайте архив

    Нажмите кнопку скачивания и получите NEXUS LAUNCHER.zip.

  2. 2

    Распакуйте в папку

    Лучше без кириллицы в пути, например C:\Games\NexusLauncher.

  3. 3

    Запустите NEXUS LAUNCHER.exe

    При первом старте лаунчер подготовит папки для версий, модов и профилей. Вкладка «Мои моды» сразу доступна всем пользователям.

  4. 4

    Выберите сборку и играйте

    Укажите ник, ядро и версию Minecraft, затем нажмите «Запустить Minecraft».

Требования

Windows 10/11, интернет для загрузки игры и модов. Для актуальных версий Minecraft нужна Java 21 — лаунчер подскажет, если версия не подходит.

Для раздела CurseForge нужен бесплатный API-ключ. Для Modrinth ключ не требуется.

// 03

Частые вопросы

Коротко о главном перед запуском.

Это официальный лаунчер Minecraft?

Нет. Это независимый лаунчер автора проекта для запуска Java-версии Minecraft и управления сборками.

Какие версии Minecraft поддерживаются?

Лаунчер работает с популярными версиями через Fabric, NeoForge, Forge, Quilt и ваниль: 1.21.10, 1.21.9, 1.21.4, 1.21.1, 1.20.6, 1.20.4, 1.20.1 и 1.12.2.

Можно ли играть без модов?

Да. Кнопка «Запустить без модов» запускает выбранную сборку без установленных модов.

Куда ставятся моды?

В папку mods профиля выбранной связки «версия / ядро». Открыть её можно кнопкой «Папка mods» прямо в лаунчере.

Как установить ваши моды?

Откройте вкладку «Мои моды» и нажмите «Установить» рядом с нужным модом. Rick Prime Nanobots 3.4.1 Requires Rick's Stuff, поэтому зависимость поставится вместе с ним.

Где исходный код?

Репозиторий открыт: github.com/kirillnikolajzen834-prog/nexus-launcher1.
